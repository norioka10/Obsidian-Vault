## 📝 主要内容要約

### 自動的な反応（クリック・実行）

現代社会の複雑さゆえ、人は特定刺激に対して機械的に反応する固定動作パターンに依存。「高価＝良質」のようなステレオタイプは便利だが、プロに悪用される脆弱性を持つ。**コントラストの原理**（順序によって差を実際より大きく感じる）が各原理を強化する。

### 返報性

「施されたら返さなければならない」という強力な社会規範。嫌いな人からの贈り物でも機能し、受け取った恩以上の代償を払う不公平な交換が生じる。**ドア・イン・ザ・フェイス法**：大きな要求→拒否→小さな本命要求で「譲歩への返報」を引き出す。

### コミットメントと一貫性

一度立場を表明すると後の行動をそれと一致させようとする。**フット・イン・ザ・ドア法**：小さな承諾から段階的に大きな承諾へ。

### 社会的証明

不確実な状況で他者の行動を正しいガイドラインとして採用。類似した他者の行動に最も強く反応。**集合的無知**：緊急事態でも周囲が動かないと助けが不要と判断。

### 好意

好きな相手からの要求に「イエス」と言いやすい。強化要因は①外見の魅力②類似性③お世辞④接触と協同⑤連合。

### 権威

専門家・地位ある人への盲従。肩書きや服装・装飾品などの記号だけで服従を引き出す。

### 希少性

手に入りにくいほど価値が増すと感じる。数量限定・タイムリミットが冷静な判断を奪う。

### 一体性

「私たちは仲間」という共有アイデンティティが最強の説得源泉（第7の原理・最新版追加）。

## 🔑 主要概念一覧

| 概念 | 定義 | 応用例 |
|---|---|---|
| **クリック・実行** | 刺激→自動的反応の固定パターン | マーケティングトリガー設計 |
| **コントラストの原理** | 順序提示で差を実際以上に大きく感じる | 価格提示順序 |
| **返報性** | 施されたら返さなければならない社会規範 | 試供品・先行サービス |
| **ドア・イン・ザ・フェイス** | 大→小の順で要求し承諾を引き出す | 交渉・営業 |
| **コミットメントと一貫性** | 立場表明後は一貫した行動をとる | 誓約・公言の活用 |
| **フット・イン・ザ・ドア** | 小→大の順で要求を段階的に通す | 営業・組織変革 |
| **社会的証明** | 他者の行動を正しい基準として採用 | 口コミ・レビュー・行列 |
| **集合的無知** | 緊急時に周囲の無行動を「問題なし」と解釈 | 傍観者効果 |
| **ウェルテル効果** | 類似状況の人への自殺報道が連鎖自殺を誘発 | メディア報道倫理 |
| **好意** | 好感を持つ相手の要求に応じやすい | 営業・ブランディング |
| **ハロー効果** | 一つの良い特性が他の評価にも波及 | 外見と能力の誤連合 |
| **権威** | 専門家・地位への盲目的服従 | 制服・肩書きの効果 |
| **希少性** | 稀少なものほど価値が高いと感じる | 限定品・期間限定 |
| **一体性** | 共有アイデンティティによる説得 | コミュニティマーケティング |
