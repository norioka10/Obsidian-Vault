## 📖 書籍概要

「入門書を読んだがわからなかった人」に向けて、統計学の**初歩の初歩だけ**を扱うと宣言した本。著者は統計学を安易に易しく見せる本を「ごまかし」と切り捨てたうえで、網羅を放棄し、**「なぜ全数調査をしなくても全体像がわかるのか」という一点のカラクリを腹落ちさせる**ことに全編を費やす。到達点は明快で、テレビの視聴率と選挙の出口調査の仕組みを自力で読み解けるようになること。数字アレルギーの編集担当者に紙と鉛筆で講義した内容を原稿化し、著者が加筆する、という作り方自体が設計思想を示している。「数式は統計学の言語であり避けて通れない」としつつ、中学数学の範囲まで噛み砕く姿勢が一貫している。

## 📝 章別要約

**プロローグ — 統計学の存在価値はコスト削減にある**
関東地区1800万世帯に対し、視聴率調査のサンプルはわずか900世帯。全国を合わせても6900世帯で、総世帯約5800万の約8400分の1にすぎない。これを「もっともらしい」と受け止められるのが統計学のわかる人、「全数調査でなければ正しいはずがない」と疑うのがわからない人、という対比から本書は始まる。前提はバイアスのないサンプリングで、電話帳を使った系統抽出からRDD（Random Digit Dialing）方式への移行など、ランダム性の確保が実務的には難しいことも率直に示される。一方で、ビジネスではバイアスのかかったデータ（購入者アンケートなど支持層の声）こそ価値を持つ場合があり、「ハガキが少ないときこそ統計学の出番」だと説く。「1〜20から10個をランダムに選べ」という演習では、人間が作為なくランダムを作れないこと、そして過不足なく列挙することも同じくらい難しいことを体感させる。

**1章 — ヒストグラムから偏差値まで**
階級と階級値を決めて度数分布表をつくり、ヒストグラムを描く。平均値は単純平均と、階級値に相対度数を掛けて足す加重平均を区別し、統計学でいう平均値は後者。偏差（データ−平均）は正負が相殺するので二乗し、度数で重みづけして平均したものが**分散**、分散にルートをかけたものが**標準偏差（S.D.）**。偏差値は「（点数−平均点）÷標準偏差×10＋50」という定義式で、同じ点数・同じ平均点でも標準偏差が変われば偏差値は変わる。標準偏差が小さいテストでは0点も100点も希少性が高くなるため両者の偏差値差は開き、大きいときは縮まる。ここから著者は「一度のテスト結果は良くても悪くても当てにならない」と結論し、同じ母集団の模試を継続受験して偏差値の平均と標準偏差を出せば、まぐれが薄まり自分の実力パターンが見えると勧める。

**2章 — 正規分布と正規化**
左右対称の山型で、多数の要因が絡み偶然性が高いデータほど現れやすい（身長、足の速さ）。後天的要因が強い体重は正規分布になりにくく、所得は典型的な非正規分布で平均値と中央値が大きくずれる。テストの成績も二極化して山が2つになりやすい。核心は「平均±標準偏差1個分に全体の約68%、2個分に約95%、3個分に約99%が含まれる」という性質。誤差の研究からこの分布を導いたのはガウスで、平均0・標準偏差1の**標準正規分布**は面積が標準正規分布表として計算済みになっている。任意の正規分布データを (X−平均)÷S.D. で変換する**正規化**を行えば、どんなデータもこの表で扱える。実務では「正規分布に従うと仮定して」分析を始めることが多いが、経済・社会の統計には正規分布でないものが多いという但し書きも置かれる。

**3章 — 二項分布**
確率分布の条件（0以上の確率が存在する／確率の合計が1／データに漏れがない）を確認したうえで、前提となる「組み合わせ」と「順列」を高校数学から復習する。結果が2通りしかない試行が**ベルヌーイ試行**で、成功確率 p の試行を n 回行い k 回成功する確率は P(X=k)=nCk × p^k × (1−p)^(n−k)。著者は「公式は覚えなくていい、書き出して数えれば解ける」と繰り返し、サイコロを3回振って1が出るパターンを総数216通りのうち91通りと数え上げることで、定理式を裏側から導いてみせる。

**4章 — 中心極限定理が両者をつなぐ**
互いに独立な確率変数を何度も繰り返すと、元の分布が何であれ n が大きくなるほど正規分布に近づく。二項分布も n が十分大きければ正規分布に酷似し、平均＝np、分散＝np(1−p) という簡潔な式で扱える。平均・分散・標準偏差の3つが決まればグラフの形が決まり、68/95/99の性質をそのまま使えるようになる。ただし二項分布はマイナス方向に広がらず頂点もやや左寄りで、完全な左右対称にはならない点は注記されている。

**5章 — 視聴率と出口調査のカラクリ**
視聴率は「見たか見なかったか」の二項分布であり、サンプル数が数百を超えれば正規分布とみなせる。誤差の幅は p ± 2√(p(1−p)/n) で求まり、n=900・視聴率10%なら**±2%**（ビデオリサーチ社の公表値と一致）。同じ式でサンプル90世帯なら±6%、9000世帯なら±0.6%になる。誤差を半分にするには標本数が4倍必要で、コストと精度の釣り合いから900世帯が選ばれている。裏を返せば、**視聴率1%の上下は誤差の範囲**で、有意な差とは言えない。出口調査も同じ構造で、候補者2人・1000人調査ではp=0.5のとき誤差が最大±3%。得票率54%以上なら95%区間の下限が過半数51%を超えるので当確、46%以下なら敗北確定と判断できる（99%水準なら±4.5%）。ただし前提のランダム性は崩れやすく、期日前投票者が調査対象外であること、答えやすい人に偏ること（賛成は言いやすく反対は言いにくい）が、2015年5月17日の大阪都構想住民投票で出口調査（賛成51.7%／反対48.3%）と開票結果が逆転した原因だと分析する。

**おわりに — 覚えようとするのは理解していないから**
用語も公式も忘れてよい。「平均から離れたデータが多いほどばらつきが大きい」と理解していれば、必要なときに分散の考え方に自力で辿り着ける。覚えようとするのは理解していない証拠だ、というのが著者の立場。エクセルの分析ツールや各国統計部局・国際機関の生データを使い、自分でデータを集めてヒストグラムを描くところまでやってはじめて身につく、と締めくくる。

## 🔑 主要概念一覧

| 概念 | 定義 | 実務での使いどころ |
|---|---|---|
| 標本調査・標本誤差 | 全数を調べずサンプルから全体を推定する。真値とのズレが標本誤差 | 調査・アンケート結果を「幅」で読む |
| ヒストグラム／度数分布表 | 階級値を横軸、度数を縦軸にとった分布の可視化 | データを見たら最初に描く |
| 分散・標準偏差 | 偏差の二乗の加重平均が分散、その平方根が標準偏差 | 平均だけでなくばらつきを併記する |
| 偏差値 | (値−平均)÷標準偏差×10＋50 | 母集団の中での相対位置を測る |
| 正規分布と68/95/99 | 平均±1/2/3S.D.に約68%/95%/99%が入る | 「異常値か誤差か」の即断基準 |
| 正規化・標準正規分布 | 平均0・標準偏差1に変換し、既成の表で確率を読む | 単位の違う指標同士の比較 |
| ベルヌーイ試行・二項分布 | 結果が2通りの試行。平均np、分散np(1−p) | 買う/買わない、当選/落選の分析 |
| 中心極限定理 | 独立な試行を重ねると分布は正規分布に近づく | 大数のサンプルを正規分布として扱う根拠 |
| サンプリングバイアス | 抽出の偏り。かかった時点で統計学は無力になる | 「誰が答えたか」を必ず点検する |

## 🛠 実務アクション

- 数字を渡されたら、値より先に**n（サンプル数）と誤差幅**を確認する。誤差の中に収まる1%の増減に反応しない。
- アンケート・満足度・受注率は二項分布として扱い、95%の幅を p ± 2√(p(1−p)/n) で概算する。n=1000なら最大±3%、n=100なら最大±10%。
- **精度を2倍にするにはサンプルを4倍**必要。調査設計はこのコスト曲線を前提に「どこで妥協するか」を先に決める。
- 平均値を単独で報告しない。標準偏差（またはレンジ）をセットで出し、ばらつきを共有する。
- 施策の効果は単月の数字でなく、継続測定した平均と標準偏差で判断する（模試の偏差値と同じ考え方）。
- 集計前に「回答していない層は誰か」を書き出す。期日前投票が出口調査に乗らないのと同じ穴が、社内調査にも必ずある。
- 所得・売上のように非対称な分布に平均値を当てないこと。正規分布を仮定してよいデータかを先に問う。
