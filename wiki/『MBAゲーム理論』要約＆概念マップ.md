## 📝 章別要約

### 第1部｜単期間ゲームと基礎概念

1回限りの「同時進行ゲーム」を扱い、ゲーム理論の根幹をなす概念を整理する。

- **絶対優位戦略（dominant strategy）**：相手の行動に関わらず、常に自分にとって最善の戦略。
- **ナッシュ均衡**：互いが相手の戦略を前提に最適行動をとり合う、安定した均衡状態。どちらも単独では逸脱しないポイント。
- **混合戦略**：特定の純粋戦略に絞れない場合、複数の戦略を確率で組み合わせることで均衡を達成する。
- **クルノー競争**：生産量を決定変数とする複占競争モデル。
- **ベルトラン競争**：価格を決定変数とする競争モデル。価格競争が激化し、完全競争に近づく。

---

### 第2部｜複数期間ゲームと協力の形成

時間軸と情報を考慮し、1回限りのゲームを超えた複雑な戦略関係を分析する。

- **交互進行ゲーム（sequential game）**：プレーヤーが順番に意思決定するゲーム。ゲームの木（展開形）で表現。
- **後向き帰納法（backward induction）**：ゲームの最終段階から逆向きに最適手を読む推論法。
- **部分ゲーム完全均衡（SPNE）**：すべての部分ゲームでナッシュ均衡が成立する均衡。「信頼できる脅し」の判別に使う。
- **反復ゲーム**：同じ相手と繰り返す取引。未来の利得を考慮するため、協力が合理的になりうる。
- **トリガー戦略（grim trigger）**：相手が裏切ったら永遠に報復する戦略。将来の利得が十分大きければ、協力が安定的に持続する。

---

### 第3部｜情報の非対称性と応用理論

プレーヤー間で保有情報が異なる場合に生じる問題と対処法を論じる。

- **情報の非対称性**：売り手と買い手、依頼人と代理人など、一方が相手より多くの情報を持つ状況。
- **逆選択（adverse selection）／レモンの問題**：品質が不明なため、買い手は低価格しか払わず、良質な財が市場から退出してしまう現象。シグナリング（資格・保証）で緩和可能。
- **モラル・ハザード**：契約後、代理人が依頼人の利益に反する行動をとるリスク。誘引両立制約（incentive-compatible contract）による設計で対処。
- **オークション理論と勝者の呪い（winner's curse）**：競争入札で落札者が財の価値を過大評価しがちな現象。
- **ナッシュ交渉解**：交渉が決裂した場合（交渉決裂点）と比較し、双方の利得増分の積を最大化する点が公正な交渉解。

---

### 第4部｜理論の限界と今後の展望

- **限定合理性（bounded rationality）**：現実の人間は完全な情報処理能力を持たず、必ずしも最適解を選ばない。
- **進化ゲーム理論（evolutionary game theory）**：学習・適応プロセスを取り込んだゲーム理論の拡張。生物学・社会科学に応用。
- **実務への示唆**：ゲーム理論は「正解を出す機械」ではなく、直感や経験を補完する論理的フレームワークとして柔軟に活用すべき。

## 🔑 主要概念一覧

| 概念 | 定義 | ビジネス応用例 |
|---|---|---|
| **絶対優位戦略** | 相手の行動によらず常に最善な戦略 | 低コスト戦略が常に有利な場合 |
| **ナッシュ均衡** | 相互最適応答の安定状態 | 価格競争の均衡点分析 |
| **混合戦略** | 複数戦略を確率的に組み合わせる | 入札・交渉でのランダム化 |
| **クルノー競争** | 生産量を変数とした複占モデル | 製造業の生産量決定 |
| **ベルトラン競争** | 価格を変数とした競争モデル | 小売・EC価格競争 |
| **後向き帰納法** | 末端から逆算して最適手を導く | M&A交渉での先読み |
| **部分ゲーム完全均衡** | すべての部分ゲームでNE成立 | 「空脅し」の見極め |
| **反復ゲーム** | 繰り返し相互作用するゲーム | 長期取引関係の分析 |
| **トリガー戦略** | 裏切りへの永続的報復 | 業界カルテルの安定条件 |
| **情報の非対称性** | 一方のみが情報を保有する状況 | 採用・融資・M&A |
| **逆選択** | 不良品が市場を駆逐する現象 | 中古車市場、保険 |
| **モラル・ハザード** | 契約後の代理人の機会主義行動 | 経営者報酬設計 |
| **勝者の呪い** | 落札者が財の価値を過大評価 | M&A、資源入札 |
| **ナッシュ交渉解** | 双方の利得増分積を最大化する点 | 労使交渉、契約交渉 |
| **限定合理性** | 人間の情報処理能力の限界 | 行動経済学との接点 |
| **進化ゲーム理論** | 学習・適応を取り込んだ拡張理論 | 市場進化・競争戦略 |
