## 📖 書籍概要

認知バイアスを、知覚・記憶・思考・意思決定・言語・創造性・集団行動の観点から整理する。バイアスを単なる愚かさではなく、限られた認知資源で環境に適応するための知性の副作用として捉える。

## 📝 主要内容要約

### バイアスは知性の影

認知バイアスは、人間の知性が特定状況で誤作動するだけでなく、限られた時間・記憶・情報の中で素早く判断するための適応的な仕組みでもある。

### 注意と記憶は限定的

人は見ているつもりでも、注意を向けていない変化には気づかない。記憶も正確な記録ではなく、後から再構成されるため、事後情報や問いかけによって変わりうる。

### 思い出しやすさと典型性が判断を歪める

利用可能性ヒューリスティックは、思い出しやすい情報を実際より多い・重要だと判断させる。代表性ヒューリスティックは、典型例に似ているかどうかを確率判断に混ぜ込み、連言錯誤やステレオタイプを生む。

### 人は自分の正しさを補強しがち

確証バイアスにより、人は自分の仮説を支持する情報を探し、反証を避けやすい。議論や調査では、自分の仮説を壊すテストを意識的に設計する必要がある。

### 言語と分析も万能ではない

言語化は理解を助けるが、顔・味・直感的パターンのような情報を無理に言葉にすると、元の認識を損なうことがある。状況モデルを作らず言葉だけを追うと、意味理解も浅くなる。

### 集団は判断をさらに歪める

同調、責任の分散、権威への服従により、個人では避けられる判断ミスが集団内で増幅される。バイアス対策には、個人の注意だけでなく、反対意見や責任の所在を明確にする仕組みが必要である。

## 🔑 主要概念一覧

| 概念 | 定義 | 応用例 |
|---|---|---|
| **認知バイアス** | 認知の仕組みが特定状況で判断を偏らせる現象 | 意思決定・議論・記憶評価 |
| **変化盲** | 注意していない変化に気づけない現象 | UI確認・現場観察 |
| **虚偽記憶** | 事後情報により記憶が再構成されること | 証言・振り返り |
| **利用可能性ヒューリスティック** | 思い出しやすさで頻度や確率を判断する傾向 | リスク評価 |
| **代表性ヒューリスティック** | 典型例への似かたで確率を判断する傾向 | 採用・分類・予測 |
| **連言錯誤** | 詳しい説明ほど確率が高そうに感じる誤り | シナリオ評価 |
| **確証バイアス** | 自説を支持する情報を優先する傾向 | 調査・デバッグ・投資判断 |
| **言語隠蔽効果** | 言語化によって非言語的記憶が損なわれる現象 | 顔認識・味覚評価 |
| **機能的固着** | 道具や方法の既存用途に縛られること | 発想・問題解決 |
| **同調バイアス** | 周囲に合わせて判断を変える傾向 | 会議・レビュー |
| **限定合理性** | 人間の合理性が時間・情報・記憶に制約されること | 経営判断・設計判断 |
| **二重過程理論** | 高速直感と低速熟慮の二系統で考えるモデル | バイアス対策 |
