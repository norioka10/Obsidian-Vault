## 📖 一言要約

ゴールドラット博士の**制約理論（[[TOC]]）**をベースに、企業が陥る「経営の通説（常識）」の誤りを科学的論理で解き明かす。マネジメントは「公式」を活用すれば必ず成果を出せる**「科学」**であり、全体最適の視点からボトルネックに集中することで、組織は劇的な成果を実現できる。

## 📝 各章の要約

### 1. マネジメントを「科学」として捉える

真の理論とは「**結果をあらかじめ予測できる体系的知識**」でなければならない。TOCの根本は「**つながり」と「ばらつき」のあるシステム**という考え方で、全体の出力は最も能力の低い**「制約（ボトルネック）」**によって決定される。複雑な現象も「ハコ（事象）・矢印（因果関係）・バナナ（複数条件）」の3道具で論理的に分析できる。

### 2. 会計の常識を疑う：スループット会計（TA）

従来の原価計算（配賦）は20世紀初頭の遺物で現代に不適合。「コストダウンすれば利益が増える」は部分最適の罠。スループット会計では3指標で管理する：**T（スループット）＝販売を通じてお金を作り出す速度**、**I（在庫）＝投資したお金**、**OE（業務費用）＝Tに変えるために費やすお金**。「変えられない過去（原価）」でなく「変えられる未来（T増大）」に集中する。

### 3. 生産マネジメント：DBR

「稼働率を上げればコストが下がる」という通説は大量在庫・長納期の元凶。DBRで全体最適を実現する：**ドラム**（制約のペースで仕事量を決定）・**バッファ**（制約を守る時間的ゆとり）・**ロープ**（原材料投入をドラムに合わせて制限）。これにより在庫最小化・リードタイム劇的短縮・市場変化への迅速対応が実現する。

### 4. サプライチェーンの革新：DBM

経済システムはカオスであり100%の需要予測は理論的に不可能。DBM（ダイナミック・バッファ・マネジメント）では在庫状況を信号機（赤・黄・青）で色分けし「**売れた分だけ補充する**」自律制御を導入。各店舗の分散在庫を中央倉庫に集約すると**統計的集約効果**でばらつきが相殺され、全体在庫を大幅削減できる。

### 5. プロジェクトマネジメント：CCPM

個々タスクに「サバ（安全余裕）」を含めると**学生症候群**（期限直前着手）と**パーキンソンの法則**（時間一杯使い切る）で必ず納期遅れになる。CCPMの解決策：タスクのサバを削り「50%確率で終わる」挑戦的期間に設定→削ったサバをプロジェクト末に**プロジェクトバッファ**として集約管理→「助けてボード」で問題を早期発見する文化を醸成。

### 6. 思考プロセス：論理的な問題解決

TOCの**思考プロセス（TP）**は因果関係を解き明かす一連のツール。**現状ツリー（CRT）**で表面的なUDE（望ましくない現象）を因果連鎖しコア・プロブレムを特定→**クラウド**で対立する主張の背景を明らかにしWin-Win解を発見→**未来現実ツリー（FRT）＋ネガティブ・ブランチ（NBR）**で解決策の良否・副作用を予測→**前提条件ツリー（PRT）**で中間目標と手順を明確化。

### 7. 提案とイノベーションの作法

優れた解決策も相手の同意がなければ実行されない。**URO（UnRefusable Offer）**：相手が変化を拒む抵抗の6段階を理解し「断れない提案」を構築する。**E4V（イノベーション）**：顧客が直面する「痛み（マイナス）」に着目し解消する価値を定義。「WOW!カタログ」で完成前から顧客に価値を問い直すプロセスが重要。

### 8. 人材育成と評価：成長ナビ

「評価すれば人は伸びる」という通説は多くの場合、減点主義となり挑戦意欲を削ぐ。**成長ナビ**は過去の結果を裁かず「変えられる未来」に焦点を当てる。**AT（Ambitious Target）面談**で本人の人生・仕事の目標オーバーラップを発見し、高い目標設定を支援。失敗を個人でなく「仮説の誤り」のせいにする**ミステリー分析**で組織全体の知恵を蓄積する。

## 🔑 主要な概念一覧

| 概念 | 説明 |
|------|------|
| 制約理論（TOC） | Theory Of Constraints。ゴールドラット博士提唱。制約に集中し全体最適を実現する経営理論 |
| ボトルネック／制約 | システム全体の出力を決定する最も能力の低い部分 |
| 全体最適 vs 部分最適 | 各部署の独立最適化は全体を悪化させる。制約集中の全体最適が正解 |
| スループット（T） | 販売を通じてお金を作り出す速度（売上－直接変数費） |
| 在庫（I） | 販売するために投資したお金。「資産」でなく「債務」と捉える |
| 業務費用（OE） | 在庫をスループットに変えるために費やすお金 |
| DBR | ドラム・バッファ・ロープ。制約のペースで全生産を制御する手法 |
| DBM | ダイナミック・バッファ・マネジメント。信号機方式の在庫自律制御 |
| 統計的集約効果 | 分散在庫を集約するとばらつきが相殺され全体在庫が大幅減少 |
| CCPM | クリティカル・チェーン・プロジェクト・マネジメント。サバをプロジェクトバッファに集約 |
| 学生症候群 | タスクに余裕を与えると期限直前まで着手しない現象 |
| パーキンソンの法則 | 与えられた時間をすべて使い切る傾向。個人バッファの弊害 |
| プロジェクトバッファ | 各タスクのサバを削ってプロジェクト末に集約した安全余裕 |
| 思考プロセス（TP） | 因果関係を解き明かすTOCのツール群（CRT・クラウド・FRT・PRT等） |
| 現状ツリー（CRT） | UDE（望ましくない現象）を因果連鎖し根本原因（コア・プロブレム）を特定 |
| クラウド | 対立する主張の背景にある要望を明らかにしWin-Win解を見つけるツール |
| 未来現実ツリー（FRT） | 解決策実行後の結果（良否・副作用）を事前に予測するツール |
| ネガティブ・ブランチ（NBR） | FRTの副作用（悪い結果）を事前把握し対策を打つツール |
| 前提条件ツリー（PRT） | 目標達成の障害と中間目標・手順を明確化するツール |
| URO | UnRefusable Offer。抵抗の6段階を理解し相手が断れない提案を設計 |
| E4V | イノベーション手法。顧客の「痛み（マイナス）」を解消する価値を定義 |
| 成長ナビ | 過去裁断ではなく未来志向の人材育成・評価フレームワーク |
| AT面談 | Ambitious Target面談。人生・仕事の目標オーバーラップを発見し高い目標を設定 |
| ミステリー分析 | 失敗を「仮説の誤り」として組織全体の学びに変える手法 |
