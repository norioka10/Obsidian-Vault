# Claude Code Artifacts × MCPコネクタ

> [!key-insight]
> アーティファクトは「セッション成果のキャプチャ」だが、**閲覧時に claude.ai コネクタを呼べる**ので、視聴者ごとにオンデマンドでデータ取得・アクション実行するダッシュボード／軽量アプリが組める。

## 何が新しいか

- ターミナル出力の代わりに、対話型の1ページ（HTML/MD）を `claude.ai` に公開できる。
- ページはバックエンドを持たない。外部への直接 `fetch` も CSP で不可。
- **例外**: 宣言した MCP コネクタを、ページ表示時（やリフレッシュ時）に呼べる。
- 呼び出しは **閲覧者のアカウント・接続・権限**で走る（作者の資格情報は使わない）。副作用のある操作も同様。

## 制約（設計前に必ず見る）

| 制約 | 意味 |
| --- | --- |
| アプリではない | フォーム永続化・複数ルート・独自APIは不可 |
| コネクタは claude.ai 側のみ | ローカル `.mcp.json` / Cursor プラグイン MCP は **構築時**だけ。公開後のライブ呼び出し対象外 |
| 共有 | コネクタ付きは公開リンク不可。Team/Enterprise は組織内共有可。Pro/Max は実質自分用 |
| 要件 | Pro/Max/Team/Enterprise、`/login`、Claude Code **v2.1.209+**（コネクタ呼び出し） |
| 未接続視聴者 | ライブ欄は空。フォールバック文言（どのコネクタが必要か）を入れておく |

## 自環境への当てはめ（2026-07-16時点）

### いまある MCP

| 場所 | サーバ | ライブ・アーティファクトで使えるか |
| --- | --- | --- |
| Claude Code（`~/.claude.json`） | Plaud（stdio / ローカル） | **構築時のみ**。公開ページのオンデマンド呼び出しには、claude.ai の Connectors に同等接続が必要 |
| Cursor（`~/.cursor/mcp.json`） | Plaud | 同上（Cursor セッション用。アーティファクト閲覧パスとは別） |
| Cursor プラグイン | Slack / Context7 | Cursor 内では利用可。アーティファクトのライブ呼び出しは **claude.ai に同名コネクタがある場合のみ** |

### 作れそうなもの（優先度つき）

1. **セッション成果の共有（コネクタ不要・すぐ使える）**
   - PR 差分ウォークスルー、調査タイムライン、設計案の並置比較。
   - リンクを渡すだけで、Slack への長文貼り付けを減らせる。

2. **Slack 朝会ボード（claude.ai に Slack コネクタがある前提）**
   - 指定チャンネルの未対応スレ／自分宛てメンションを一覧。
   - ボタンで下書き投稿やリアクション（実行は閲覧者アカウント）。
   - 共同編集者には各自の Slack 接続と初回承認が必要。

3. **Plaud フォローアップ・ダッシュボード（要確認）**
   - 直近録音の要約・アクション一覧、`get_note` / `list_files` 相当。
   - **現状のローカル Plaud MCP だけでは公開後にリフレッシュできない**。claude.ai Connectors に Plaud（または同等のリモート）があるか確認してから本命化する。
   - 当面の代替: セッション中に Plaud から取ったスナップショットで静的ボードを出す／定期的に再 publish。

4. **学習・Wiki 用の操作盤（部分的）**
   - Obsidian Vault はローカルのため、ライブコネクタ向きではない。
   - 「問いインデックスから選んでプロンプトをコピー」など、セッション内完結の UI は相性が良い。

### やらない方がよいこと

- Cursor のローカル MCP だけを前提に「開くたびに最新」と約束する（仕様上破綻する）。
- コネクタ付きページを社外公開リンクで共有しようとする（不可）。
- バックエンド付きの社内ツール代替として期待する（公式も「deploy yourself」と明記）。

## 次の一手（実務）

1. Claude Code を **v2.1.209+** に上げ、`/login` 済みか確認。
2. claude.ai → Settings → Connectors で、使いたい接続（特に Slack / Plaud 相当）があるか確認。
3. パイロット1本: **コネクタ不要の PR ウォークスルー**で公開〜共有の感触を取る。
4. 通ったら Slack 朝会ボードをコネクタ付きで試作（フォールバック文言必須）。
