## 📖 書籍概要

論理学の基本を、命題・否定・接続・条件文・推論という順に学ぶ入門書。日常会話の曖昧さと、論理学で扱う形式的な正しさを切り分けることで、議論を筋道立てて評価するための道具を提供する。

## 📝 主要内容要約

### 論理とは形式を見る道具

論理は「話の筋道」であり、内容の好みではなく形式の正しさを検討する。共通の経験や価値観を持たない相手と議論するためには、誰が見ても追える筋道が必要になる。

### 命題と否定

命題とは、真か偽かを判定できる文である。否定は単なる反対語ではなく、元の主張を打ち消すすべての可能性を含む。矛盾律と排中律は、命題の真偽を考える基礎になる。

### 接続と条件文

「かつ」は両方が真のときだけ真、「または」は少なくとも一方が真なら真になる。条件文「AならばB」では、日常語のニュアンスと論理学の扱いにズレがあるため、必要条件・十分条件の区別が重要になる。

### 逆・裏・対偶

「AならばB」に対して、逆・裏・対偶を区別する。元の命題が真なら必ず真になるのは対偶であり、逆や裏は同じ真偽になるとは限らない。

### 推論を評価する

演繹は前提が真なら結論も必ず真になる形式、帰納は事例から一般化する形式、仮説形成は事実を説明する仮説を置く形式である。日常の議論では隠れた前提を復元し、その前提の妥当性も確認する必要がある。

## 🔑 主要概念一覧

| 概念 | 定義 | 応用例 |
|---|---|---|
| **命題** | 真偽を判定できる文 | 議論の最小単位 |
| **否定** | 元の主張を打ち消す操作 | 反対語との混同を避ける |
| **連言** | AかつB | 条件の同時成立 |
| **選言** | AまたはB | 少なくとも一方の成立 |
| **ド・モルガンの法則** | 連言・選言の否定変換 | 条件整理・仕様確認 |
| **必要条件** | それがなければ成り立たない条件 | 資格要件・前提条件 |
| **十分条件** | それがあれば成り立つ条件 | 判定基準・トリガー |
| **対偶** | BでないならAでない | 論証の言い換え |
| **演繹** | 前提から必然的に結論を導く推論 | 数学的証明・仕様検証 |
| **帰納** | 事例から一般法則を導く推論 | データ分析・経験則 |
| **仮説形成** | 観察事実を説明する仮説を置く推論 | 原因分析・デバッグ |
| **隠れた前提** | 明示されていないが推論に必要な前提 | 議論の穴の発見 |
