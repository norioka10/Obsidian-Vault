## 📝 主要内容要約

### 1｜二つの思考システム

- **システム1（速い思考）**：直感的・情動的・自動的。進化で生存のために発達。「見たものがすべてだ（WYSIATI）」の原則で拙速に結論を出す。
- **システム2（遅い思考）**：注意力を要する論理的推論を司る。非常に「怠け者」で、多くの場合システム1の判断をそのまま採用してしまう。

### 2｜ヒューリスティクスとバイアス

難しい問いを簡単な問いに置き換える「近道（ヒューリスティクス）」が体系的エラーを生む。

- **アンカリング効果**：最初に見た数字が基準になり判断を歪める。
- **利用可能性ヒューリスティック**：思い出しやすい事象の確率を過大評価する。
- **代表性ヒューリスティック**：ステレオタイプに合致するかで判断し、基準率を無視する。
- **プライミング効果**：先行刺激が無意識のうちに後の行動・判断に影響する。

### 3｜プロスペクト理論

- **損失回避性**：損失の苦痛は利得の喜びの約2倍。保有効果を生む。
- **参照点依存性**：富の絶対量でなく現状からの変化で価値を判断する。
- **フレーミング効果**：「生存率90%」と「死亡率10%」で意思決定が変わる。

### 4｜二つの自己

- **経験する自己**：今この瞬間を感じる自己。
- **記憶する自己**：過去を振り返り物語を紡ぐ自己。意思決定を支配する。
- **ピーク・エンドの法則**：記憶の評価はピーク時と終了時の印象で決まり、持続時間は無視される。

## 🔑 主要概念一覧

| 概念 | 定義 | 応用例 |
|---|---|---|
| **システム1** | 直感・感情・自動処理 | 顔認識、即座の判断 |
| **システム2** | 論理・注意・努力的処理 | 複雑な計算、意識的選択 |
| **WYSIATI** | 見えている情報だけで結論を出す傾向 | 不完全情報での過信 |
| **コグニティブ・イーズ** | 認知的楽さを求める傾向 | 馴染みあるものを好む |
| **アンカリング効果** | 最初の数値が基準になる | 価格交渉・見積もり |
| **利用可能性ヒューリスティック** | 思い出しやすさ＝確率と錯覚 | リスク過大評価 |
| **代表性ヒューリスティック** | ステレオタイプで判断し基準率を無視 | 採用・投資判断 |
| **プライミング効果** | 先行刺激が後の反応を誘発 | マーケティング・環境設計 |
| **後知恵バイアス** | 結果を知った後に「最初から分かっていた」と感じる | 評価・学習の歪み |
| **計画の錯誤** | 自分の計画を楽観的に見積もる | プロジェクト管理 |
| **損失回避性** | 損失の苦痛＝利得の喜びの約2倍 | 保険・投資行動 |
| **保有効果** | 所有するものに高い価値を感じる | 売却判断・交渉 |
| **フレーミング効果** | 表現の違いで判断が変わる | 医療インフォームド・政策 |
| **参照点依存性** | 現状を基準に価値判断する | 給与交渉・割引 |
| **ピーク・エンドの法則** | 記憶はピークと終了時で決まる | UX設計・サービス体験 |
| **プロスペクト理論** | 利得より損失を重視した価値関数 | 行動経済学・政策設計 |
| **経験する自己** | 現在進行中の体験を感じる自己 | 幸福度研究 |
| **記憶する自己** | 過去の物語として経験を整理する自己 | 意思決定・後悔 |
