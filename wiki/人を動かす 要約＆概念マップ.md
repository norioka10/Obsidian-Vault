## 📖 書籍概要

デール・カーネギー著（1936年）。時代を超えて読み継がれる人間関係の金字塔。人は「重要感を持たれたい」という根源的欲求を持っており、それを満たすことが相手を動かす鍵。テクニックではなく「相手への誠実な関心と敬意」を根底に置く。

## 📝 主要内容要約

### 第1部｜人を動かす三原則

1. **批判も非難もせず、苦情も言わない**：批判は自尊心を傷つけ反抗心を生む。相手が「なぜそうしたか」を理解する寛容さが第一歩。
2. **率直で誠実な評価を与える**：お世辞でなく、相手の長所を心から認める誠実な感謝で「重要感」を満たす。
3. **強い欲求を起こさせる**：相手が何を欲しているかに焦点を合わせ、相手の利益になる方法を提示する。

### 第2部｜人に好かれる六原則

1. 誠実な関心を寄せる
2. 笑顔を忘れない
3. 名前を覚える（人にとって最も快い言葉）
4. 聞き手にまわる（話し上手になるには聞き上手になる）
5. 関心のありかを見抜く
6. 心からほめる（相手に重要感を持たせる黄金律）

### 第3部｜人を説得する十二原則（主要6つ）

1. **議論を避ける**：議論に勝っても心を傷つけ協力は得られない。
2. **誤りを指摘しない**：相手の自尊心を傷つけず誤りを気づかせる。
3. **誤りを認める**：自分が間違った時は即座・潔く認める。
4. **穏やかに話す**：怒りや強制でなく親しみやすい態度で。
5. **"イエス"と答えられる問題を選ぶ**：同意できる話題から始める。
6. **人の身になる**：相手の立場で考え、「あなたがそう感じるのは当然です」と共感する。

## 🔑 主要概念一覧

| 概念 | 定義 | 応用例 |
|---|---|---|
| **重要感の欲求** | 誰もが持つ「重要な存在でありたい」という根源的欲求 | リーダーシップ・動機付け |
| **誠実な評価** | お世辞でなく心からの感謝と称賛 | フィードバック・1on1 |
| **相手の欲求への焦点化** | 相手が何を欲しているかを起点にする | 提案営業・交渉 |
| **聞き手になる** | 話し上手は聞き上手。相手が喜んで話せる環境を作る | コーチング・面談 |
| **名前の力** | 相手の名前を使うことで重要感を伝える | 顧客対応・コミュニティ |
| **議論を避ける** | 議論に勝っても関係は損なわれる | 交渉・会議ファシリテーション |
| **誤りを認める** | 素直に認めることで相手の寛大さを引き出す | クレーム対応・謝罪 |
| **"イエス"から始める** | 同意できる話題から入り拒絶を防ぐ | 提案・説得 |
| **人の身になる** | 相手の立場で考える共感力 | マネジメント・交渉 |
| **ドア・イン・ザ・フェイス** | 大きな要求→小さな本命要求の順 | 交渉戦術 |
| **フット・イン・ザ・ドア** | 小さな承諾から段階的に大きな承諾へ | 習慣化・組織変革 |
