## 📖 書籍概要

デジタル化によって世界の価値の中心は「見える世界（モノ・具体・五感で捉えられるもの）」から「見えない世界（抽象概念・関係性・構造・データ）」へ移った。ところが人間の視野はスマホ化に象徴されるようにむしろ狭まっている。この**拡大する見えない世界と、狭まる視野とのギャップ**が本書の出発点である。著者はギャップの正体を「具体の谷」と名づけ、そこから抜け出す道具として**抽象化**と**「無知の知」**を提示する。

## 📝 章別要約

### 第1章 加速するVUCAの時代と見えない世界

見える世界は「物理的・具体的・五感で感じられる・ハードウェア・アナログなモノづくり・個別事象」、見えない世界は「精神的・抽象概念・五感で感じられない・ソフトウェア・デジタルなICTやデータ・関係性や構造」。両者は性質からして違い、見える世界が「足し算・一次関数的変化・コピー有料・差が付きにくい・有限」なのに対し、見えない世界は「掛け算・指数関数的変化・コピー無料・差が付きやすい・無限」（図2）。コロナ禍や株価・時価総額の激変が示すのは、この掛け算の世界では能力や成果の差が桁違いに開くという構造である。

### 第2章 人は見えるものばかりを追いかける

スマホは時計・辞書・地図・カメラ・手帳などを飲み込んだ（図5）が、同時に**2つの視野狭窄**を招いた。ひとつは小さな画面しか見ないという物理的な狭まり、もうひとつは関係性・抽象という「見えないもの」を見なくなる狭まりである（図8・図9）。サッカーの好パスが「いま誰もいない方向」に蹴られるように、価値は見えないものを想像する力から生まれる（図10）。過去は確定し正解があり知識の対象だが、未来は未確定で正解がなく想像と創造の対象である（図11）。したがって「あるものから」の発想（具体に着目・過去の経験と知識重視・データと論理重視・受動的）ではなく、「ないものから」の発想（具体を抽象化・想像と創造重視・直感とアブダクション重視・能動的）が要る（図12）。

### 第3章 「見えないもの」としての抽象

動物と人間では見ている世界が違う（図6）。人間だけが抽象概念を扱えるからだ。抽象化とは細部を捨てて**全体像を見ること**であり（図13）、具体抽象ピラミッドの上方ほど視野が広がる（図7）。十進法という抽象概念があるかないかで世界の見え方が一変するように（図14）、抽象概念は認識の道具そのものである。

### 第4章 抽象化とは線を引くこと

抽象化の実体は「線を引く」ことであり、役割は2通りある（図16）。ひとつは**区別**の線引き（図17）、もうひとつは複数を**まとめて一つにする**線引き＝カテゴライズ（図18〜図20）で、これに**関係付け**の線引きが加わる（図25）。具体的事象は空間と時間を超えられないが、抽象化して言葉にすれば時空を超えて共有・継承できる。これが人間の抽象化能力の発展メカニズムであり（図22）、動物のコミュニケーション範囲との決定的な差になった（図21・図23）。一方で線引きは必ず**歪み**を伴う（図27・図28）。国家や宗教のような大集団を成立させた抽象概念が、同時に差別・対立といった構造的矛盾と社会的課題を生んだ（図29）。

### 第5章 見えない抽象の次元

抽象には**次元**がある（図31）。0次元＝点＝二値（白か黒か）で「正誤」の世界。1次元＝線（座標）＝程度の比較の世界でスペクトラムを扱える。N次元＝複数の座標軸＝多面評価。そして無限次元＝もはや座標では表現不能な「見えない」世界。人物の捉え方に当てはめると、「良い人」「賛成派」という二値 → 「身長〇cm」「年収〇万円」という数値 → 多値 → 「〇〇さんは〇〇さん」という無限の視点となり、対応する価値観はそれぞれ**正誤・比較・多様性・ありのまま**へと移る（図38）。実際の世界は多次元・無限次元なのに、人間の世界観の分布は「正誤で考える人」に大きく偏っている（図41）。

### 第6章 「具体の谷」とは

縦軸に具体⇄抽象、横軸に視野の広さを取ると、視野は単調に広がらない。具体そのものに素直に留まる人も、抽象度を十分に上げた人も視野は広いが、**中途半端に具体化・専門化した領域で視野が最も狭くなる**。この窪みが「具体の谷」である（図46）。ワインの例が分かりやすい。素人は「ワイン」とひとくくりにできるが、知識が増える途上では「これは全部違う」と細分化が進み、かえって視野が狭くなる（図50〜図52）。専門家がざっくりした一般化を嫌う姿勢は、そのまま抽象化の妨げになりうる。谷を深くするのが**部分と全体のバイアス**で、Web記事の見出しだけで断じる、切り取られた発言だけで人を評する、といった振る舞いがこれにあたる（図43〜図45）。谷の位置は抽象の次元と対応し、「0&1次元＝正誤と優劣」「N次元＝無知の無知」「無限次元＝無知の知」と重なる（図48）。

### 第7章 見えない世界を見るための「無知の知」

「単なる無知」は知識が不足している状態で、いかにも愚者に見える非メタレベルの無知。対して「無知の無知」は知識に慢心した状態で、いかにも賢人に見えるメタレベルの無知であり、**気づいていないこと自体が最大の問題**である（図53）。世界は①既知、②既知の未知、③未知の未知に分かれるが、「無知の無知」の世界観では③が眼中にない（図55）。この3つの輪は仕事のレベル分けにそのまま対応する。①はマニュアルのあるルーチンワーク、②は「問題解決」の対象（プロジェクト）、③は「問題発見」の対象だ（図58・図59）。「無知の無知」の人は、ルールと常識が通用する「場内」だけを世界だと思い、例外的な「場外」を認識しない（図61）。3つの世界観は報酬構造まで違い、0次元は「合格すればもらえる」、N次元は「労力に比例する」、無限次元は「リスクに比例する」（図63）。

### おわりに

抽象化と「無知の知」は、人間が抽象化能力とともに背負ってしまった根源的な知の欠陥を戒めるものであり、時代を超えて語り継がれるべき考え方である。著者は「次元」という言葉を共通言語として広め、仕事・教育・生活の場で見えない世界を見る手がかりにしてほしいと結ぶ。

## 🔑 主要概念一覧

| 概念 | 定義 | 応用例 |
|---|---|---|
| **見える世界／見えない世界** | 物理・具体・足し算 ⇄ 抽象・関係性・掛け算 | 事業価値の所在の把握 |
| **具体の谷** | 中途半端な具体化・専門化で視野が最も狭くなる窪み | 専門家の思考の点検 |
| **抽象化＝線を引くこと** | 区別・まとめて一つにする・関係付けの3種の線引き | 分類設計・概念整理 |
| **具体抽象ピラミッド** | 知識量と抽象度で世界を階層化した図 | 議論の階層を合わせる |
| **抽象の次元** | 0次元（正誤）／1次元（比較）／N次元（多面）／無限次元 | 自分の見方の自己診断 |
| **「あるものから」／「ないものから」** | 過去データ起点 ⇄ 想像と創造起点 | 新規事業・企画の発想 |
| **部分と全体のバイアス** | 切り取られた一部で全体を断じる歪み | SNS・報道への向き合い方 |
| **無知の無知／無知の知** | 慢心による盲点 ⇄ 未知の未知の自覚 | 学習計画・意思決定 |
| **3つの輪** | 既知／既知の未知／未知の未知 | ルーチン・問題解決・問題発見の棚卸し |
| **場内／場外** | ルールと常識が通用する世界 ⇄ 通用しない世界 | 例外・非常識領域の想定 |
| **抽象化による歪み** | 線引きが必然的に生む区別と矛盾 | 差別・対立の構造理解 |
| **時空を超える抽象** | 言葉にすれば具体事象の空間・時間の制約を外せる | 知識の共有と継承 |

## ✅ 実務アクション

1. 資料や会議で「見える数字」だけを並べていないか点検し、**関係性と構造**を1枚の図に起こして添える。
2. 判断の前に「いま自分は何次元で見ているか」を自問する（正誤／比較／多面／ありのまま）。0次元の断定に気づいたら一段上げる。
3. 見出しや切り取り発言に反応する前に、**全文 → 元の論文・書籍 → 背景**へ最低1段さかのぼってから意見を持つ。
4. 専門を深める作業と並行して「ざっくり一般化して言い直す」時間を確保し、具体の谷に落ちないようにする。
5. 自分の仕事を3つの輪で棚卸しし、②問題解決だけでなく**③問題発見に割く時間を明示的に確保**する。
6. 未来を語る場では過去データの延長（あるものから）を封じ、「ないものから」の問いを1つ立ててから議論を始める。
7. 定期的に「自分が知らないことを知らない領域」を書き出し、社外・異業種など「場外」の情報源を意識的に1本持つ。
