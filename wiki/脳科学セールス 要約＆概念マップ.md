## 📖 書籍概要

「脳科学セールス」の本質は、単なるテクニックではなく、人間の脳の仕組み（感情と論理）を理解し、顧客が自然に「選択」したくなるプロセスを設計することにある。真の競合は他社ではなく、顧客自身の「現状維持」という心理であり、これを打破するための体系的アプローチを提供する。

## 📝 章別要約

**1. 購買心理の根本：脳の仕組みと信頼の原則**  
人は「感情で決め、論理で正当化する」。専門家としてのスキルより先に、人間として信頼される必要がある。コミュニケーションの核心は「なぜ（動機）」を理解してから「何を（提案）」を届けること。

**2. 意思決定を左右する6つの認知バイアス**  
①プロスペクト理論（損失回避：利益の喜びより損失の恐怖が約2倍強い）、②アンカリング効果（最初の情報が基準になる）、③選択支持バイアス（過去の選択を正当化したい）、④確証バイアス（自分の信念を裏付ける情報だけを集める）、⑤利用可能性ヒューリスティック（思い出しやすい情報を正しいと判断）、⑥バンドワゴン効果（多くの人が選んでいる安心感）。

**3. 最大のライバル「現状維持」の壁を突破する**  
現状維持の代償を数値化し、変化によって得られる価値がリスクを上回ることを示す。比較対象を「他社製品」ではなく「問題を解決しなかった時の将来的な代償」に再設定する。

**4. 物語（ストーリー）の力と成約へのロードマップ**  
セールス・ロードマップ（5ステップ）：①信頼の構築→②世界観の理解→③問題の総括→④解決策の物語→⑤自然な選択（「お客様は、どうなさいたいですか？」と問いかけ顧客自身が選ぶ）。

**5. 結論：営業の真の定義**  
「顧客の問題を解決するという形で、顧客の役に立つこと」。顧客が自らの意思で「現状を変えたい」と決断できるよう、心理的な環境を整えること。

## 🔑 主要概念一覧

| 概念         | 定義                     | 活用方法                  |     |

| プロスペクト理論   | 損失を避ける恐怖は利益の喜びの約2倍強い   | 現状維持の代償（損失）を先に提示する    |     |
| アンカリング効果   | 最初に提示された情報が判断の基準となる    | 解決策の価格より先に「問題の損失額」を示す |     |
| 選択支持バイアス   | 自分の過去の選択を正当化したい心理      | 「変えた選択は正しい」と背中を押す     |     |
| 確証バイアス     | 自分の信念を裏付ける情報だけを収集する傾向  | 物語（ストーリー）で感情に先に訴えかける  |     |
| バンドワゴン効果   | 多くの人が選んでいる事実に安心感を覚える   | 社会的証明（実績・事例・口コミ）を提示   |     |
| 現状維持バイアス   | 変化よりも現状を維持しようとする心理     | 「変化しないリスク」を具体的に数値化する  |     |
| セールスロードマップ | 信頼→理解→総括→物語→選択の5段階プロセス | 段階的に顧客の心理的ハードルを下げる    |     |
