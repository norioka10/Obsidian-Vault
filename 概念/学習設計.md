# 学習設計

## 定義

知識を読むだけで終わらせず、理解、記憶、実践、振り返りへ接続するために学び方を設計する考え方。
第二の脳では、要約だけでなく「どの問いに使うか」まで結びつける。

## 実務での適用

- インプット直後に、自分の言葉で要約し、使いどころを1つ決める。
- 学んだ内容を問い・概念・実務アクションへ接続する。
- 定期的に [[問いインデックス]] と [[概念/概念インデックス]] を見直し、使わない知識を整理する。
