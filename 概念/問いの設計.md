# 問いの設計

答えの質は問いの質で決まる。前提を疑う問い、相手の思考を広げる問いかけ、自分への問いの立て方は、問題解決・対話・学習すべての起点になる。

## 実務での適用

- 会議では「答えを出す前に、問いが正しいか」を最初の5分で確認する
- AIとの協働では問いの設計がそのままプロンプト設計になる
- 人を見極める場面では、答えを知っている問いをあえて投げ、正解ではなく推論の過程と理解の深さを見る（エヌビディアCEOジェンスン・フアンの面接・リファレンスチェック手法 → [[エヌビディアCEOが「本当に優秀な人」を一発で見抜く“実力がバレる質問”（要約）|記事要約]]）
- 指示は問いの形に変換できる（フアンは指示の約9割が質問混じり）。成功直後にこそ「もっとうまくできたことは何か」と問う — 失敗後の反省は誰でも口にできるが、成功の中で不足を探せるかは別問題
